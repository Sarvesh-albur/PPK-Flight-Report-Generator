PPK flight report

Add a flight column, drop its 4 files: result.csv, camera-command CSV, TIM2 CSV and *_events.pos (other PPK files are ignored) and the sheet fills itself.

Filled automatically: pictures (camera file), TIM2 (TIM2 file). Each camera command is paired with the next TIM2 event; commands with no event are interpolated images, and total points = selected − interpolated. Selected images = pictures unless a result.csv is added. Total points, fix, float and single are all counted directly from the events.pos file: total = number of rows, fix = Q1, float = Q2, single = anything else; fix = total − float − single. Drone ID, project and flight are typed by you. Every number can be corrected by hand.
